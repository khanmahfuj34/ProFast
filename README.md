# Zep Shift – Smart Parcel Delivery & Rider Management System

Zep Shift is a modern full-stack logistics and parcel delivery management platform inspired by real-world delivery systems like Pathao, RedX, and Steadfast. The project is built with a complete role-based architecture where Users, Riders, and Admins have separate dashboards and functionalities. The platform focuses on parcel booking, live delivery workflow, rider management, notifications, support system, analytics, and real-time delivery monitoring.

The system includes a fully functional parcel delivery lifecycle. Users can create parcel delivery requests, track parcels, manage addresses, view notifications, create support tickets, and monitor delivery history from their personalized dashboard. Riders receive delivery requests automatically through the rider panel and can manage delivery statuses such as Accepted, Picked Up, On The Way, Delivered, or Cancelled. Admins can monitor the entire delivery ecosystem from a professional admin dashboard with delivery control, rider approval management, parcel monitoring, analytics, notifications, and support ticket handling.

The Admin Dashboard contains advanced operational sections including Delivery Control, Approve Riders, Manage Users, All Parcels, Reports & Analytics, Notifications, Payment History, and Support Tickets. The Delivery Control section dynamically tracks all delivery statuses in real-time and displays live parcel activity using backend-driven APIs. Admins can inspect full delivery details including sender information, receiver information, assigned rider, payment status, and delivery timeline. Rider approval workflows are also fully integrated with verification-based approval and status monitoring.

The platform also includes a complete Notification Center system. Admins can send broadcast notifications to users and riders, while users and riders receive role-specific notifications directly inside their dashboards. A real-time support ticket system allows users to communicate directly with admins through ticket replies and status updates.

Reports & Analytics provides beginner-friendly business insights including revenue charts, parcel delivery statistics, delivery status distribution, top riders, and date-based filtering. All analytics data is dynamically fetched from backend APIs and optimized for dashboard visualization.

The project follows a scalable backend architecture using Express.js, MongoDB, Firebase Authentication, JWT security, modular routes, controllers, services, socket integration, and reusable APIs. The frontend is built using React, Tailwind CSS, Framer Motion, React Router, Axios, TanStack Query, and responsive dashboard layouts optimized for desktop and mobile devices.

The codebase is structured professionally with separated frontend and backend folders, reusable components, modular backend logic, protected routes, role-based access control, and optimized state management. The project is currently under active development and future updates will include advanced Zone Management, Live Tracking, Smart Rider Assignment, Real-Time Maps, and AI-powered delivery optimization features.
